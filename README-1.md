## Просмотр в Mirador

После развёртывания GitHub Pages скопируйте [адрес manifest.json](https://vladislavmakarevic495-afk.github.io/Arhive/picheta-iiif/manifest.json). В [Mirador Demo](https://projectmirador.org/demo/) нажмите «+», выберите Add resource и вставьте адрес манифеста. Листы открываются в порядке с 25-го по 30-й.

## Размещение на GitHub Pages

Папка `picheta-iiif` размещается в корне ветки `main` [репозитория Arhive](https://github.com/vladislavmakarevic495-afk/Arhive). В Settings → Pages выберите Deploy from a branch, ветку `main` и папку `/(root)`.
